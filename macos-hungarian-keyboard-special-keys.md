
# macOS Hungarian keyboard special sharacters

 Char | Key                  | Char | Key
------|----------------------|------|------------------------
 \;   | option .:            | \&   | option 1
 \*   | option shift ,?      | \#   | option shift 3
 \^   | option I<BR>option Á | \<   | option shift Y
 \|   | option Í             | \>   | option shift X
 \~   | option N<BR>option Ú | \{   | option 7
 \\   | option Ü             | \}   | option Ö
 \@   | option Q             | \[   | option 8
 \`   | option Ű             | \]   | option 9
 \$   | option 4             |      |

 PC key    | Mac Key
-----------|----------------------------------------------------------
 PAGE UP   | fn up
 PAGE DOWN | fn down
 HOME      | fn left
 END       | fn right
 DEL       | fn backspace
 PrtScr    | shift command 3 (full screenshot -> file)
 PrtSrc    | shift command 4 (select area -> file)
 PrtScr    | control shift command 3 (full screenshot -> clipboard)
 PrtScr    | control shift command 4 (select area -> clipboard)
